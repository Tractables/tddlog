arith_fw_medium

Cao et al.'s integer arithmetic programs (UAI 2023), Pluck's sequence models (PLDI 2025) and noDice's purely probabilistic programs (OOPSLA 2026). Alea.jl runs an Alea.jl program itself; tddlog and Dice run the Boolean circuit Alea.jl builds for it, and Roulette that circuit's Dice program translated to Racket. The noDice programs are Dice programs, translated, and Roulette runs them translated to Racket. 600 s a run. Geni, noDice, Psi, Genfer, SPPL, Pluck, PITA, aspmc, Storm, PRISM, Ace, Merlin, pyAgrum, pgmpy, libDAI and TensorInference.jl ran too, each on the programs it takes (its own paper's, the Dice programs, the ProbLog programs or the networks); a system's time is its process's, start-up included. Roulette, Roulette's process, Geni, noDice, Psi, Genfer, SPPL, Pluck, PITA, aspmc, Storm, PRISM, Ace, Merlin, pyAgrum, pgmpy, libDAI and TensorInference.jl ran in a later run, on other machines, on the instances the release run did not give them. Seconds, a time limit of 600 s; >600: the time limit ran out. memory: out of memory. error: the system stopped with an error. skipped: not run: the system had failed on a smaller size of the same program. A process time is the whole process's, with the language's start and compilation; the other time of the same system leaves them out, as its paper times it. A time is the median of the repetitions below, a failed one counted as infinite. A system run in several forms (ProbLog's knowledge compilers, Ace's routes) has the time of its fastest form.

# Ported from experiments/dicejl/fw_medium.jl of Tractables/Alea.jl,
# branch arithmetic, commit 7e9ff23517086eb4518845e50218bf18b4d9f2a5
# (Apache License 2.0). Mechanical port: Dice -> Alea, @dice -> @alea, the
# BenchmarkTools harness dropped, the query moved to QUERY.
# Cao, Garg, Holtzen, Van den Broeck, Millstein (UAI 2023), Table 1: floydwarshall-medium.
using Alea

const QUERY = :pr

model() = @alea begin
    num_nodes = 6
    MAX = 3 * num_nodes * num_nodes
    w = Int(floor(log2(MAX))) + 2

    edges = Dict(
        (1, 2) => uniform(DistUInt{w}, 1, 3),
        (1, 3) => uniform(DistUInt{w}, 1, 5),
        (1, 6) => uniform(DistUInt{w}, 1, 11),
        (2, 3) => uniform(DistUInt{w}, 1, 3),
        (2, 5) => uniform(DistUInt{w}, 1, 7),
        (3, 5) => uniform(DistUInt{w}, 1, 5),
        (4, 5) => uniform(DistUInt{w}, 1, 3),
        (5, 6) => uniform(DistUInt{w}, 1, 3)
    )

    distance = [[DistUInt{w}(MAX) for j in 1:num_nodes] for i in 1:num_nodes]


    for edge in edges
        coord, dist = edge[1], edge[2]
        distance[coord[1]][coord[2]] = dist
        distance[coord[2]][coord[1]] = dist
    end

    for i in 1:num_nodes
        distance[i][i] = DistUInt{w}(0)
    end

    for k in 1:num_nodes
        for i in 1:num_nodes
            for j in 1:num_nodes
                distance[i][j] = ifelse(distance[i][j] > distance[i][k]+distance[k][j], distance[i][k]+distance[k][j], distance[i][j])
            end
        end
    end

    distance[1][6]
end

arith_triangle_small

Cao et al.'s integer arithmetic programs (UAI 2023), Pluck's sequence models (PLDI 2025) and noDice's purely probabilistic programs (OOPSLA 2026). Alea.jl runs an Alea.jl program itself; tddlog and Dice run the Boolean circuit Alea.jl builds for it, and Roulette that circuit's Dice program translated to Racket. The noDice programs are Dice programs, translated, and Roulette runs them translated to Racket. 600 s a run. noDice, Psi, Pluck, Storm and PRISM ran too, each on the programs it takes (its own paper's, the Dice programs or the ProbLog programs); a system's time is its process's, start-up included. Roulette, Roulette's process, Storm and PRISM ran in a later run, on other machines, on the instances the release run did not give them, each beside tddlog: their times compare with that run's tddlog, not with the other columns, and the comparisons below use it. # Ported from experiments/dicejl/triangle_small.jl of Tractables/Alea.jl,
# branch arithmetic, commit 7e9ff23517086eb4518845e50218bf18b4d9f2a5
# (Apache License 2.0). Mechanical port: Dice -> Alea, @dice -> @alea, the
# BenchmarkTools harness dropped, the query moved to QUERY.
# Cao, Garg, Holtzen, Van den Broeck, Millstein (UAI 2023), Table 1: triangle-small.
using Alea

const QUERY = :pr

model() = @alea begin
    a = uniform(DistInt{15},-50, 51)
    b = uniform(DistInt{15},-50, 51)
    c = uniform(DistInt{15},-50, 51)



    zero = DistInt{15}(0)


    type =
        ifelse((a <= zero) | (b <= zero) | (c <= zero),
            DistUInt{2}(3),
        ifelse(
            (a+b<=c) | (a+c<=b) | (b+c <= a),
            DistUInt{2}(3),
        ifelse(
            prob_equals(a, b) & prob_equals(a, c) & prob_equals(b, c),
            DistUInt{2}(2),
        ifelse(
            prob_equals(a, b) | prob_equals(a, c) | prob_equals(b, c),
            DistUInt{2}(1),
            DistUInt{2}(0)
        ))))

    type

end

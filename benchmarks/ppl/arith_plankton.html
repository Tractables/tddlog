arith_plankton

Cao et al.'s integer arithmetic programs (UAI 2023), Pluck's sequence models (PLDI 2025) and noDice's purely probabilistic programs (OOPSLA 2026). Alea.jl runs an Alea.jl program itself; tddlog and Dice run the Boolean circuit Alea.jl builds for it. The noDice programs are Dice programs, translated, and Roulette runs them translated to Racket. 600 s a run. noDice, Psi and Pluck ran too, each on the programs it takes (its own paper's, the Dice programs or the ProbLog programs); a system's time is its process's, start-up included. The circuit of the Alea.jl program data/alea/arith/plankton.jl.

# Ported from experiments/dicejl/plankton.jl of Tractables/Alea.jl,
# branch arithmetic, commit 7e9ff23517086eb4518845e50218bf18b4d9f2a5
# (Apache License 2.0). Mechanical port: Dice -> Alea, @dice -> @alea, the
# BenchmarkTools harness dropped, the query moved to QUERY.
# Not in Table 1 of Cao et al. (UAI 2023).
using Alea

const QUERY = :pr

model() = @alea begin
    function binomial(n::DistUInt{W}, p, max::Int) where W
        output = DistUInt{W}(0)
        for i in 0:max-1
            output += ifelse((DistUInt{W}(i)<n) & flip(p), DistUInt{W}(1), DistUInt{W}(0))
        end
        return output
    end


    param = uniform(DistUInt{7}, 10, 51)
    planktoncount = binomial(param, 0.5, 50)
    planktoncount
end

arith_tugofwar

Cao et al.'s integer arithmetic programs (UAI 2023), Pluck's sequence models (PLDI 2025) and noDice's purely probabilistic programs (OOPSLA 2026). Alea.jl runs an Alea.jl program itself; tddlog and Dice run the Boolean circuit Alea.jl builds for it, and Roulette that circuit's Dice program translated to Racket. The noDice programs are Dice programs, translated, and Roulette runs them translated to Racket. 600 s a run. Geni, noDice, Psi, Genfer, SPPL, Pluck, PITA, aspmc, Storm, PRISM, Ace, Merlin, pyAgrum, pgmpy, libDAI and TensorInference.jl ran too, each on the programs it takes (its own paper's, the Dice programs, the ProbLog programs or the networks); a system's time is its process's, start-up included. Roulette, Roulette's process, Geni, noDice, Psi, Genfer, SPPL, PITA, aspmc, Storm, PRISM, Ace, Merlin, pyAgrum, pgmpy, libDAI and TensorInference.jl ran in a later run, on other machines, on the instances the release run did not give them, each beside tddlog: their times compare with that run's tddlog, not with the other columns, and the comparisons below use it. The circuit of the Alea.jl program data/alea/arith/tugofwar.jl.

A process time is the whole process's, with the language's start and compilation; the other time of the same system leaves them out, as its paper times it. A time is the median of the repetitions below, a failed one counted as infinite. A system run in several forms (ProbLog's knowledge compilers, Ace's routes) has the time of its fastest form.

# Ported from experiments/dicejl/tugofwar.jl of Tractables/Alea.jl,
# branch arithmetic, commit 7e9ff23517086eb4518845e50218bf18b4d9f2a5
# (Apache License 2.0). Mechanical port: Dice -> Alea, @dice -> @alea, the
# BenchmarkTools harness dropped, the query moved to QUERY.
# Cao, Garg, Holtzen, Van den Broeck, Millstein (UAI 2023), Table 1: tugofwar.
using Alea

const QUERY = :pr

model() = @alea begin
players = Vector(undef, 6)

players[1] = discrete(DistUInt{9}, [0.015625, 0.09375, 0.234375, 0.3125, 0.234375, 0.09375, 0.015625]) + DistUInt{9}(142);
players[2] = discrete(DistUInt{9}, [0.015625, 0.09375, 0.234375, 0.3125, 0.234375, 0.09375, 0.015625]) + DistUInt{9}(146);
players[3] = discrete(DistUInt{9}, [0.015625, 0.09375, 0.234375, 0.3125, 0.234375, 0.09375, 0.015625]) + DistUInt{9}(150);
players[4] = discrete(DistUInt{9}, [0.015625, 0.09375, 0.234375, 0.3125, 0.234375, 0.09375, 0.015625]) + DistUInt{9}(143);
players[5] = discrete(DistUInt{9}, [0.015625, 0.09375, 0.234375, 0.3125, 0.234375, 0.09375, 0.015625]) + DistUInt{9}(145);
players[6] = discrete(DistUInt{9}, [0.015625, 0.09375, 0.234375, 0.3125, 0.234375, 0.09375, 0.015625]) + DistUInt{9}(140);


cheat_player = uniform(DistUInt{3}, 0, 6)
cheat_player2 = uniform(DistUInt{3}, 0, 6)
observe(!prob_equals(cheat_player, cheat_player2))

final_players = Vector(undef, 6)
for i in 1:6
    final_players[i] = ifelse(prob_equals(cheat_player, DistUInt{3}(i-1)) | prob_equals(cheat_player2, DistUInt{3}(i-1)), players[i]+DistUInt{9}(10), players[i])
end

a = final_players[1]
b = final_players[2]
c = final_players[3]
d = final_players[4]
e = final_players[5]
f = final_players[6]


result_3 = a+b+e<c+d+f
result_5 = a+c+d<b+e+f
result_6 = a+c+e<b+d+f
result_10 = a+e+f<b+c+d

observe(result_3 & result_5 & result_6 & result_10)
(cheat_player == DistUInt{3}(5)) | (cheat_player2 == DistUInt{3}(5))
end

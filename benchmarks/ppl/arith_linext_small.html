arith_linext_small

Cao et al.'s integer arithmetic programs (UAI 2023), Pluck's sequence models (PLDI 2025) and noDice's purely probabilistic programs (OOPSLA 2026). Alea.jl runs an Alea.jl program itself; tddlog and Dice run the Boolean circuit Alea.jl builds for it, and Roulette that circuit's Dice program translated to Racket. The noDice programs are Dice programs, translated, and Roulette runs them translated to Racket. 600 s a run. Geni, noDice, Psi, Genfer, SPPL, Pluck, PITA, aspmc, Storm, PRISM, Ace, Merlin, pyAgrum, pgmpy, libDAI and TensorInference.jl ran too, each on the programs it takes (its own paper's, the Dice programs, the ProbLog programs or the networks); a system's time is its process's, start-up included. Roulette, Roulette's process, Geni, noDice, Psi, Genfer, SPPL, Pluck, PITA, aspmc, Storm, PRISM, Ace, Merlin, pyAgrum, pgmpy, libDAI and TensorInference.jl ran in a later run, on other machines, on the instances the release run did not give them, each beside tddlog: their times compare with that run's tddlog, not with the other columns, and the comparisons below use it. # Ported from experiments/dicejl/linext_small.jl of Tractables/Alea.jl,
# branch arithmetic, commit 7e9ff23517086eb4518845e50218bf18b4d9f2a5
# (Apache License 2.0). Mechanical port: Dice -> Alea, @dice -> @alea, the
# BenchmarkTools harness dropped, the query moved to QUERY.
# Cao, Garg, Holtzen, Van den Broeck, Millstein (UAI 2023), Table 1: linext-small.
using Alea

const QUERY = :pr

model() = @alea begin

    uniq_count = 4

    bits = Int(floor(log2(uniq_count)) + 4)
    partial = [[1, 3], [1, 4]]

    ranks = [uniform(DistInt{bits}, 0, uniq_count) for i in 1:uniq_count]
    for i in 1:uniq_count
        for j in i+1:uniq_count
            observe(!prob_equals(ranks[i], ranks[j]))
        end
    end


    for comp in partial
        observe(ranks[comp[1]] < ranks[comp[2]])
    end

    (ranks[1], ranks[2], ranks[3], ranks[4])
end

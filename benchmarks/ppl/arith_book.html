arith_book

Cao et al.'s integer arithmetic programs (UAI 2023), Pluck's sequence models (PLDI 2025) and noDice's purely probabilistic programs (OOPSLA 2026). Alea.jl runs an Alea.jl program itself; tddlog and Dice run the Boolean circuit Alea.jl builds for it, and Roulette that circuit's Dice program translated to Racket. The noDice programs are Dice programs, translated, and Roulette runs them translated to Racket. 600 s a run. noDice, Psi, Pluck, Storm and PRISM ran too, each on the programs it takes (its own paper's, the Dice programs, the ProbLog programs or the networks); a system's time is its process's, start-up included. Roulette, Roulette's process, Storm and PRISM ran in a later run, on other machines, on the instances the release run did not give them, each beside tddlog: their times compare with that run's tddlog, not with the other columns, and the comparisons below use it. The circuit of the Alea.jl program data/alea/arith/book.jl.

# Ported from experiments/dicejl/book_mod.jl of Tractables/Alea.jl,
# branch arithmetic, commit 7e9ff23517086eb4518845e50218bf18b4d9f2a5
# (Apache License 2.0). Mechanical port: Dice -> Alea, @dice -> @alea, the
# BenchmarkTools harness dropped, the query moved to QUERY.
# Cao, Garg, Holtzen, Van den Broeck, Millstein (UAI 2023), Table 1: book.
using Alea

const QUERY = :pr

model() = @alea begin
curValue = uniform(DistInt{14}, 1, 501)
tgtValue = uniform(DistInt{14}, 1, 501)



delta = tgtValue - curValue

for i=1:1
    d = ifelse((delta < DistInt{14}(5)) & (delta > DistInt{14}(-5)),
        DistInt{14}(0),
        ifelse(delta < DistInt{14}(0),

            ifelse(delta > DistInt{14}(-25),
            delta + uniform(DistInt{14}, -10, 11),
            ifelse(delta > DistInt{14}(-50),
            delta + uniform(DistInt{14}, -20, 21),
            ifelse(delta > DistInt{14}(-100),
            delta + uniform(DistInt{14}, -50, 51),
            delta + uniform(DistInt{14}, -100, 101)))),

            ifelse(delta < DistInt{14}(25),
            delta + uniform(DistInt{14}, -10, 11),
            ifelse(delta < DistInt{14}(50),
            delta + uniform(DistInt{14}, -20, 21),
            ifelse(delta < DistInt{14}(100),
            delta + uniform(DistInt{14}, -50, 51),
            delta + uniform(DistInt{14}, -100, 101))))
        )
    )

    curValue = curValue + d

    curValue = ifelse(curValue > DistInt{14}(500),
                    DistInt{14}(500),
                ifelse(curValue < DistInt{14}(1),
                    DistInt{14}(1),
                    curValue))

    delta = tgtValue - curValue
end

(delta < DistInt{14}(5)) && (delta > DistInt{14}(-5))
end

arith_ranking_medium

Cao et al.'s integer arithmetic programs (UAI 2023), Pluck's sequence models (PLDI 2025) and noDice's purely probabilistic programs (OOPSLA 2026). Alea.jl runs an Alea.jl program itself; tddlog and Dice run the Boolean circuit Alea.jl builds for it, and Roulette that circuit's Dice program translated to Racket. The noDice programs are Dice programs, translated, and Roulette runs them translated to Racket. 600 s a run. Geni, noDice, Psi, Genfer, SPPL, Pluck, PITA, aspmc, Storm, PRISM, Ace, Merlin, pyAgrum, pgmpy, libDAI and TensorInference.jl ran too, each on the programs it takes (its own paper's, the Dice programs, the ProbLog programs or the networks); a system's time is its process's, start-up included. Roulette, Roulette's process, Geni, noDice, Psi, Genfer, SPPL, Pluck, PITA, aspmc, Storm, PRISM, Ace, Merlin, pyAgrum, pgmpy, libDAI and TensorInference.jl ran in a later run, on other machines, on the instances the release run did not give them. The circuit of the Alea.jl program data/alea/arith/ranking_medium.jl.

# Ported from experiments/dicejl/ranking_medium.jl of Tractables/Alea.jl,
# branch arithmetic, commit 7e9ff23517086eb4518845e50218bf18b4d9f2a5
# (Apache License 2.0). Mechanical port: Dice -> Alea, @dice -> @alea, the
# BenchmarkTools harness dropped, the query moved to QUERY.
# Cao, Garg, Holtzen, Van den Broeck, Millstein (UAI 2023), Table 1: ranking-medium.
using Alea

const QUERY = :pr

model() = @alea begin
    uniq_count = 4
    bits = Int(floor(log2(uniq_count)) + 4)

    rankings = [[3, 2, 1, 0],
                [1, 3, 2, 0],
                [1, 2, 3, 0]]

    ranks = [uniform(DistInt{bits}, 0, uniq_count) for i in 1:uniq_count]
    for i in 1:uniq_count
        for j in i+1:uniq_count
            observe(!prob_equals(ranks[i], ranks[j]))
        end
    end


    for data in rankings
        obs_rank = [x + uniform(DistInt{bits}, -uniq_count, uniq_count+1) for x in ranks]
        for i in 1:uniq_count-1
            a, b = data[i]+1, data[i+1] + 1
            observe(obs_rank[a] < obs_rank[b])
        end
    end

    (ranks[1], ranks[2], ranks[3], ranks[4])
end

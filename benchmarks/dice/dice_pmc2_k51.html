dice_pmc2_k51

The programs and Bayesian networks of the Dice paper (Holtzen, Van den Broeck and Millstein, OOPSLA 2020), a network as one Dice program per queried variable, and its loop programs scaled up. tddlog runs them translated to ProbLog, Alea.jl translated to Julia, Roulette translated to Racket. 300 s a run (600 s on the loop programs). noDice, Psi, Genfer, Storm and PRISM ran too, each on the programs it takes (its own paper's, the Dice programs or the ProbLog programs); a system's time is its process's, start-up included. Storm and PRISM ran in a later run, on other machines, on the instances the release run did not give them, each beside tddlog: their times compare with that run's tddlog, not with the other columns, and the comparisons below use it. Made by dice2problog.py dice_pmc2_k51.dice.

The programs

The files each system was handed, byte for byte: written by the release's scripts at the run's commit and captured by running the benchmark driver's own code with no system started. The first tab is the original program as its authors wrote it; each other tab is a translation of it into the language of the systems that read it, and says which script wrote it.

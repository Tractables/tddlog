dice_pmc1_k20

The programs and Bayesian networks of the Dice paper (Holtzen, Van den Broeck and Millstein, OOPSLA 2020), a network as one Dice program per queried variable, and its loop programs scaled up. tddlog runs them translated to ProbLog, Alea.jl translated to Julia, Roulette translated to Racket. 300 s a run (600 s on the loop programs). noDice, Psi and Genfer ran too, each on the programs it takes (its own paper's or the Dice programs); a system's time is its process's, start-up included. Made by dice2problog.py dice_pmc1_k20.dice.

Seconds, a time limit of 600 s; >600: the time limit ran out. A process time is the whole process's, with the language's start and compilation; the other time of the same system leaves them out, as its paper times it. A time is the median of the repetitions below, a failed one counted as infinite.

The programs

The files each system was handed, byte for byte: written by the release's scripts at the run's commit and captured by running the benchmark driver's own code with no system started. The first tab is the original program as its authors wrote it; each other tab is a translation of it into the language of the systems that read it, and says which script wrote it.

The original: the program as its authors wrote it, handed to Dice, noDice as it is.

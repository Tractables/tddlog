tpch_q3v_5

The TPC-H queries as Boolean queries over a tuple-independent database, at scale factors 0.001 to 0.1, flat and through views (208 instances); 600 s a run. Ace, Merlin, pyAgrum, pgmpy, libDAI, TensorInference.jl, Storm, PRISM and the Dice family ran in a later run. Made by gen_tpch.py 0.005 --queries q3 --seed 1 --views.

Seconds, a time limit of 600 s; >600: the time limit ran out. memory: out of memory. skipped: not run: the system had failed on a smaller size of the same program. A process time is the whole process's, with the language's start and compilation; the other time of the same system leaves them out, as its paper times it. A system run in several forms (ProbLog's knowledge compilers, Ace's routes) has the time of its fastest form.

Psi (later run)
Psi answers the Dice programs exactly, one run per component of the program's value, the times added. On its own linear regression it answers the posterior means of the continuous model, E(a) and E(b), which the circuit's bit queries do not have, so there is nothing to compare them with.
Not run in any repetition: not run: the system had failed on a smaller size of the same program.


Genfer (later run)
Genfer answers its own program: the Dice programs of its comparison in exact rationals, the population model in floating point (its masses summed over the bits of the circuit).
Not run in any repetition: not run: the system had failed on a smaller size of the same program.


SPPL (later run)
SPPL answers the continuous model, with normal emissions as densities; the circuit rounds them to a grid, so the differences from the reference are that discretization.
Not run in any repetition: not run: the system had failed on a smaller size of the same program.


Geni (later run)

bb_weekend_w18

The programs of the bit-blasting paper (Garg, Holtzen, Van den Broeck and Millstein, PLDI 2024) on ladders of precision. Alea.jl runs each program itself; tddlog runs the circuit Alea.jl builds for it, and Roulette the circuit's Dice program translated to Racket. Dice's times on these circuits come from an earlier run, so they are in docs/benchmarks.md and not here. 600 s a run. Psi, Genfer, SPPL, Storm and PRISM ran too, each on the programs it takes (its own paper's, the Dice programs or the ProbLog programs); a system's time is its process's, start-up included. Roulette, Roulette's process, Storm and PRISM ran in a later run, on other machines, on the instances the release run did not give them, each beside tddlog: their times compare with that run's tddlog, not with the other columns, and the comparisons below use it. 29 more instances of the ladders no system ran: each system had failed on a smaller size. The circuit of the Alea.jl program data/alea/hybit/weekend.jl with precision=14.

# weekend (Gehr et al. 2016): whether it is a weekend given an hour drawn
# from one of two normal distributions. Bit-blasting paper (Garg, Holtzen,
# Van den Broeck, Millstein, PLDI 2024), Table 2: 24 bits, 4096 pieces.
# From Tractables/Alea.jl hybrid/benchmarks/weekend/weekend.jl at cf5e5b8
# (Apache License 2.0), its body unchanged.
using Alea, Distributions

const QUERY = :pr
const precision = 20
const num_pieces = 4096
const DFiP = DistFix{4+precision, precision}

model() = @alea begin
    isWeekend = flip(2/7)
    hour = if isWeekend
        bitblast_exponential(DFiP, Normal(5, 4), num_pieces, 0.0, 8.0)
    else
        bitblast_exponential(DFiP, Normal(2, 4), num_pieces, 0.0, 8.0)
    end
    observe(hour == DFiP(6.0))
    isWeekend
end

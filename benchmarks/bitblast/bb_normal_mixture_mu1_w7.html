bb_normal_mixture_mu1_w7

The programs of the bit-blasting paper (Garg, Holtzen, Van den Broeck and Millstein, PLDI 2024) on ladders of precision. Alea.jl runs each program itself; tddlog runs the circuit Alea.jl builds for it, and Roulette the circuit's Dice program translated to Racket. 600 s a run. Geni, noDice, Psi, Genfer, SPPL, PITA, aspmc, Storm, PRISM, Ace, Merlin, pyAgrum, pgmpy, libDAI and TensorInference.jl ran too, each on the programs it takes (its own paper's, the Dice programs, the ProbLog programs or the networks); a system's time is its process's, start-up included. Dice, Roulette, Roulette's process, ProbLog, Geni, noDice, Psi, Genfer, SPPL, PITA, aspmc, Storm, PRISM, Ace, Merlin, pyAgrum, pgmpy, libDAI and TensorInference.jl ran in a later run, on other machines, on the instances the release run did not give them, each beside tddlog: their times compare with that run's tddlog, not with the other columns, and the comparisons below use it. 27 more instances of the ladders no system ran: each system had failed on a smaller size. The circuit of the Alea.jl program data/alea/hybit/normal_mixture_mu1.jl with precision=1.

# normal_mix (mu1) (Huang et al. 2021): a mixture of two normal
# distributions, its weight theta and means mu1 and mu2 inferred from 40
# observed points; the expectation of mu1. Bit-blasting paper (Garg,
# Holtzen, Van den Broeck, Millstein, PLDI 2024), Table 2: 9 bits, 16
# pieces. From Tractables/Alea.jl
# hybrid/benchmarks/normal_mixture/normal_mixture.jl at cf5e5b8 (Apache
# License 2.0), its body unchanged, run with flag 2.
using Alea, Distributions

const QUERY = :expectation
const precision = 3
const num_pieces = 16
const flag = 2
const DFiP = DistFix{6+precision, precision}
const ys = DFiP.([10.0787617156523, -9.51866467444093, 9.73922587306449, 11.5662681883816, 9.62798489000074, -9.60265090119919, 8.90114345923455, 10.866328444034, 10.5347883361026, 8.60577222463504, -10.625227428575, -9.08615131315038, -8.99280046532217, 9.43533905966944, 8.92696803962787, 9.642301288006, 9.42066621557773, 9.90838406119759, 9.63911912487384, 7.55585122379505, 9.58069898235901, 9.63228461457187, -9.99589804304319, 8.61024296515084, -10.4988882191036, -8.45028703711596, 9.76066425342707, -8.68129886943495, 9.83763492226261, 7.29698608457303, 8.78881675784227, 10.6057117460834, 10.2807363791435, 9.54352982843898, -10.9911972452721, 12.2061931600758, 7.76887153466896, 10.7523541087606, -9.98525551020183, 10.6248182699128])

model() = @alea begin
    theta = uniform(DFiP, 0.0, 1.0)
    mu1 = bitblast_exponential(DFiP, Normal(-10, 1), num_pieces, -18.0, -2.0)
    mu2 = bitblast_exponential(DFiP, Normal(10, 1), num_pieces, 2.0, 18.0)
    for y in ys
        c1 = bitblast_exponential(DFiP, Normal(0, 1), num_pieces, -8.0, 8.0)
        c2 = bitblast_exponential(DFiP, Normal(0, 1), num_pieces, -8.0, 8.0)
        a = ifelse(parametrised_flip(theta), mu1 + c1, mu2 + c2)
        observe(a == y)
    end
    if flag == 1
        theta
    elseif flag == 2
        mu1
    else
        mu2
    end
end

bb_laplace_w13

The programs of the bit-blasting paper (Garg, Holtzen, Van den Broeck and Millstein, PLDI 2024) on ladders of precision. Alea.jl runs each program itself; tddlog runs the circuit Alea.jl builds for it, and Roulette the circuit's Dice program translated to Racket. 600 s a run. Geni, noDice, Psi, Genfer, SPPL, aspmc, Storm, PRISM, Ace, Merlin, pyAgrum, pgmpy, libDAI and TensorInference.jl ran too, each on the programs it takes (its own paper's, the Dice programs, the ProbLog programs or the networks); a system's time is its process's, start-up included. Dice, Roulette, Roulette's process, ProbLog, Geni, noDice, Psi, Genfer, SPPL, aspmc, Storm, PRISM, Ace, Merlin, pyAgrum, pgmpy, libDAI and TensorInference.jl ran in a later run, on other machines, on the instances the release run did not give them, each beside tddlog: their times compare with that run's tddlog, not with the other columns, and the comparisons below use it. 29 more instances of the ladders no system ran: each system had failed on a smaller size. The circuit of the Alea.jl program data/alea/bitblast/laplace.jl with bits=6.

# A mixture of two Laplace distributions observed under normal noise: a
# location a, Laplace around 0 or 1 (probability 1/2 each) of scale
# 1/64, and four points observed, each a + g with g standard normal; the
# query is the expectation of a. From Tractables/Alea.jl
# hybrid/benchmarks/laplace_scaling/laplace_scaling.jl at cf5e5b8 (Apache
# License 2.0; the bit-blasting paper's repository, Garg, Holtzen, Van den
# Broeck, Millstein, PLDI 2024), at its commented setting (10 bits after
# the binary point, 1024 pieces, scale 0.015625): the sizes it reads from
# the command line are constants and the location is drawn inside the
# block; the body is otherwise unchanged. The Laplace distributions are
# Alea's `laplace`, two exponentials bit blasted exactly; each observation
# is gaussian_observe's g + a == datapt, g in `pieces` linear pieces.
using Alea, Distributions

const QUERY = :expectation
const bits = 10
const pieces = 1024
const scale = 0.015625
const DFiP = DistFix{7 + bits, bits}
const data = [-0.5, -0.75, 1.75, 1.5]

model() = @alea begin
    a = ifelse(flip(0.5),
               laplace(DFiP, 0.0, scale, -8.0, 8.0),
               laplace(DFiP, 1.0, scale, -7.0, 9.0))
    for datapt in data
        gaussian_observe(DFiP, pieces, -8.0, 8.0, a, 1.0, DFiP(datapt), add=true, exp=true)
    end
    a
end

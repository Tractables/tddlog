bb_altermu2_w15

The programs of the bit-blasting paper (Garg, Holtzen, Van den Broeck and Millstein, PLDI 2024) on ladders of precision. Alea.jl runs each program itself; tddlog runs the circuit Alea.jl builds for it. Dice's times on these circuits come from an earlier run, so they are in docs/benchmarks.md and not here. 600 s a run. Psi, Genfer and SPPL ran too, each on the programs it takes (its own paper's or the Dice programs); a system's time is its process's, start-up included. 29 more instances of the ladders no system ran: each system had failed on a smaller size. The circuit of the Alea.jl program data/alea/hybit/altermu2.jl with bits=9.

# altermu2 (Nishihara et al. 2013): the mean of the first of two uniform
# parameters whose sum is the mean of 40 observed normal data points.
# Bit-blasting paper (Garg, Holtzen, Van den Broeck, Millstein, PLDI 2024),
# Table 2: 17 bits, 256 pieces. From Tractables/Alea.jl
# hybrid/benchmarks/altermu2/altermu2.jl at cf5e5b8 (Apache License 2.0),
# its body unchanged.
using Alea, Distributions

const QUERY = :expectation
const bits = 11
const pieces = 256
const DFiP = DistFix{6+bits, bits}
const truncation = (-8.0, 8.0)
const data = DFiP.([-2.57251482,  0.33806206,  2.71757796,  1.09861336,  2.85603752,
        -0.91651351,  0.15555127, -2.68160347,  2.47043789,  3.47459025,
        1.63949862, -1.32148757,  2.64187513,  0.30357848, -4.09546231,
        -1.50709863, -0.99517866, -2.0648892 , -2.40317949,  3.46383544,
        0.91173696,  1.18222221,  0.04235722, -0.52815171,  1.15551598,
        -1.62749724,  0.71473237, -1.08458812,  4.66020296,  1.24563831,
        -0.67970862,  0.93461681,  1.18187607, -1.49501051,  2.44755622,
        -2.06424237, -0.04584074,  1.93396696,  1.07685273, -0.09837907])

model() = @alea begin
    mu1 = uniform(DFiP, -8.0, 8.0)
    mu2 = uniform(DFiP, -8.0, 8.0)
    mu = mu1 + mu2
    for datapoint in data
        g = bitblast_exponential(DFiP, Normal(0, 1), pieces, truncation[1], truncation[2])
        observe(g + mu == datapoint)
    end
    mu1
end

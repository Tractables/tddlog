bb_addFun_sum_w17

The programs of the bit-blasting paper (Garg, Holtzen, Van den Broeck and Millstein, PLDI 2024) on ladders of precision. Alea.jl runs each program itself; tddlog runs the circuit Alea.jl builds for it. Dice's times on these circuits come from an earlier run, so they are in docs/benchmarks.md and not here. 600 s a run. Psi, Genfer, SPPL, Storm and PRISM ran too, each on the programs it takes (its own paper's, the Dice programs or the ProbLog programs); a system's time is its process's, start-up included. Storm and PRISM ran in a later run, on other machines, on the instances the release run did not give them, each beside tddlog: their times compare with that run's tddlog, not with the other columns, and the comparisons below use it. 29 more instances of the ladders no system ran: each system had failed on a smaller size. # Addfun/sum (Gehr et al. 2016): the sum of two of three standard normal
# numbers. Bit-blasting paper (Garg, Holtzen, Van den Broeck, Millstein,
# PLDI 2024), Table 2: 23 bits, 16 pieces. From Tractables/Alea.jl
# hybrid/benchmarks/addFun_sum/addFun_sum.jl at cf5e5b8 (Apache License
# 2.0), its body unchanged.
using Alea, Distributions

const QUERY = :expectation
const bits = 18
const pieces = 16
const DFiP = DistFix{5+bits, bits}
const indices = [1, 0, 1]

model() = @alea begin
    x = Vector(undef, 3)
    for i=1:3
        x[i] = bitblast(DFiP, Normal(0, 1), pieces, -8.0, 8.0)
    end
    sum = DFiP(0.0)
    for i=1:3
        sum = ifelse(indices[i] == 1, sum + x[i], sum)
    end
    sum
end

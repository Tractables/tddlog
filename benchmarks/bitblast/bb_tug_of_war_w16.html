bb_tug_of_war_w16

The programs of the bit-blasting paper (Garg, Holtzen, Van den Broeck and Millstein, PLDI 2024) on ladders of precision. Alea.jl runs each program itself; tddlog runs the circuit Alea.jl builds for it, and Roulette the circuit's Dice program translated to Racket. 600 s a run. Geni, noDice, Psi, Genfer, SPPL, Pluck, PITA, aspmc, Storm, PRISM, Ace, Merlin, pyAgrum, pgmpy, libDAI and TensorInference.jl ran too, each on the programs it takes (its own paper's, the Dice programs, the ProbLog programs or the networks); a system's time is its process's, start-up included. Dice, Roulette, Roulette's process, ProbLog, Geni, noDice, Pluck, PITA, aspmc, Storm, PRISM, Ace, Merlin, pyAgrum, pgmpy, libDAI and TensorInference.jl ran in a later run, on other machines, on the instances the release run did not give them. 27 more instances of the ladders no system ran: each system had failed on a smaller size. The circuit of the Alea.jl program data/alea/hybit/tug_of_war.jl with bits=11.

# Tug of war (Huang et al. 2021): two players' skills, each a normal
# distribution, four observed matches where a player may be lazy, and the
# probability that the first wins a fifth. Bit-blasting paper (Garg,
# Holtzen, Van den Broeck, Millstein, PLDI 2024), Table 2: 22 bits, 16
# pieces. From Tractables/Alea.jl hybrid/benchmarks/tug_of_war/tug_of_war.jl
# at cf5e5b8 (Apache License 2.0); DFiP moved out of the block, the body
# otherwise unchanged (it draws each skill twice, as the source does).
using Alea, Distributions

const QUERY = :pr
const bits = 17
const pieces = 16
const DFiP = DistFix{bits + 5, bits}

model() = @alea begin
    alice_skill = bitblast_exponential(DFiP, Normal(5, 1), pieces, -3.0, 13.0)
    bob_skill = bitblast_exponential(DFiP, Normal(5, 1), pieces, -3.0, 13.0)
    alice_skill = bitblast_exponential(DFiP, Normal(5, 1), pieces, -3.0, 13.0)
    bob_skill = bitblast_exponential(DFiP, Normal(5, 1), pieces, -3.0, 13.0)
    lazy_lag = DFiP(2.0)
    match = Vector(undef, 5)
    for i = 1:5
        match[i] = (ifelse(flip(1/3), alice_skill - lazy_lag, alice_skill) < (ifelse(flip(1/3), bob_skill - lazy_lag, bob_skill)))
    end
    observe(match[1])
    observe(!match[2])
    observe(match[3])
    observe(!match[4])
    match[5]
end

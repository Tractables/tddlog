# Bayesian linear regression (R2's LinearRegression, Nori, Hur, Rajamani
# and Samuel, AAAI 2014, as PSI has it, Gehr, Misailovic and Vechev, CAV
# 2016, test/r2/linearRegression.psi of github.com/eth-sri/psi at
# 622f00e, Boost Software License 1.0): a slope a ~ N(0, 1) and an
# intercept b ~ N(5, 1.8257) (PSI's prior, a variance), and n observations
# y_k ~ N(a x_k + b, 1). The data are R2's (data/LinearRegression/dataX1.csv
# and dataY1.csv there): x_k = -2 + 0.004 k and y_k for k = 1 .. 1000, of
# which the program observes the n points k = round(1000 j / n), j = 1 .. n.
# R2 and PSI give the noise a gamma prior on its precision; here its
# standard deviation is 1, so that the posterior is the conjugate normal
# one (data/alea/psi/README.md). The program returns (a, b), whose
# expectations are queried.
#
# Bit blasting: a and b are normals in `pieces` exponential pieces on
# [-8, 8] and [-3, 13]; each observation is g + a x_k + b == y_k, g a
# standard normal on [-8, 8] (gaussian_observe's form), x_k and y_k
# rounded down to the grid. `bits` is the bits after the binary point,
# `n` the number of observations.

model() = @alea begin
    a = bitblast_exponential(DFiP, Normal(0, 1), pieces, -8.0, 8.0)
    b = bitblast_exponential(DFiP, Normal(5, sqrt(1.8257)), pieces, -3.0, 13.0)
    for j in 1:n
        k = round(Int, 1000 * j / n)
        g = bitblast_exponential(DFiP, Normal(0, 1), pieces, -8.0, 8.0)
        observe(prob_equals(g + a * DFiP(-2 + 0.004 * k) + b, DFiP(Y1[k])))
    end
    (a, b)
end

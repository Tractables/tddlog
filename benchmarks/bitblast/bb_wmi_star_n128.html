bb_wmi_star_n128

The programs of the bit-blasting paper (Garg, Holtzen, Van den Broeck and Millstein, PLDI 2024) on ladders of precision. Alea.jl runs each program itself; tddlog runs the circuit Alea.jl builds for it, and Roulette the circuit's Dice program translated to Racket. Dice's times on these circuits come from an earlier run, so they are in docs/benchmarks.md and not here. 600 s a run. Psi, Genfer, SPPL, Storm and PRISM ran too, each on the programs it takes (its own paper's, the Dice programs, the ProbLog programs or the networks); a system's time is its process's, start-up included. Roulette, Roulette's process, Storm and PRISM ran in a later run, on other machines, on the instances the release run did not give them, each beside tddlog: their times compare with that run's tddlog, not with the other columns, and the comparisons below use it. 29 more instances of the ladders no system ran: each system had failed on a smaller size. # Weighted model integration on a star (Zeng, Morettin, Yan, Passerini and
# Van den Broeck, ICML 2020, Section 6; the star-shaped primal graphs of
# Zeng and Van den Broeck, UAI 2019): a centre x_0 and n leaves, real
# variables uniform on [0, 1], each leaf constrained by x_0 + x_i <= 1,
# and the query x_1 <= 1/2. The constraints have volume 1/(n+1), and the
# continuous answer is (n+1)/(2n) (1 - 2^-n) + 2^-(n+1); the answer of the
# discretized program converges to it as the bits after the binary point
# grow. Each variable is a uniform fixed-point number with `bits` bits
# after the binary point; `n` is the number of leaves.
using Alea

const QUERY = :pr
const n = 16
const bits = 8
const DFiP = DistFix{2 + bits, bits}

model() = @alea begin
    x0 = uniform(DFiP, 0.0, 1.0)
    x = [uniform(DFiP, 0.0, 1.0) for i in 1:n]
    for i in 1:n
        observe(!(DFiP(1.0) < x0 + x[i]))
    end
    !(DFiP(0.5) < x[1])
end

bb_GPA_w19

The programs of the bit-blasting paper (Garg, Holtzen, Van den Broeck and Millstein, PLDI 2024) on ladders of precision. Alea.jl runs each program itself; tddlog runs the circuit Alea.jl builds for it, and Roulette the circuit's Dice program translated to Racket. Dice's times on these circuits come from an earlier run, so they are in docs/benchmarks.md and not here. 600 s a run. Psi, Genfer, SPPL, Storm and PRISM ran too, each on the programs it takes (its own paper's, the Dice programs or the ProbLog programs); a system's time is its process's, start-up included. Roulette, Roulette's process, Storm and PRISM ran in a later run, on other machines, on the instances the release run did not give them, each beside tddlog: their times compare with that run's tddlog, not with the other columns, and the comparisons below use it. 29 more instances of the ladders no system ran: each system had failed on a smaller size. The circuit of the Alea.jl program data/alea/hybit/GPA.jl with bits=14.

# GPA (Wu et al. 2018): whether a student is from the first of two
# countries given a GPA of 0, each country's GPA a mixture of a scaled beta
# distribution and two point masses. Bit-blasting paper (Garg, Holtzen, Van
# den Broeck, Millstein, PLDI 2024), Table 2: 25 bits, 4096 pieces. From
# Tractables/Alea.jl hybrid/benchmarks/GPA/GPA.jl at cf5e5b8 (Apache
# License 2.0), its body unchanged.
using Alea, Distributions

const QUERY = :pr
const bits = 20
const pieces = 4096
const DFiP = DistFix{bits + 5, bits}

model() = @alea begin
    d1 = bitblast_exponential(DFiP, 4*Beta(8, 2), pieces, 0.0, 4.0)
    d2 = bitblast_exponential(DFiP, 8*Beta(5, 5), pieces, 0.0, 8.0)
    gpa1 = if flip(0.95) d1 else
            if flip(0.15) DFiP(4.0) else
                DFiP(0.0)
            end
        end
    gpa2 = if flip(0.99) d2 else
                if flip(0.1) DFiP(8.0) else
                    DFiP(0.0)
                end
            end
    n = flip(0.25)
    final = if n gpa1 else gpa2 end
    observe(prob_equals(final, DFiP(0.0)))
    n
end

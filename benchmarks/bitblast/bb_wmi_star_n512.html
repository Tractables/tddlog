bb_wmi_star_n512

The programs of the bit-blasting paper (Garg, Holtzen, Van den Broeck and Millstein, PLDI 2024) on ladders of precision. Alea.jl runs each program itself; tddlog runs the circuit Alea.jl builds for it, and Roulette the circuit's Dice program translated to Racket. 600 s a run. Dice, Roulette, Roulette's process, ProbLog, Geni, noDice, Pluck, PITA, aspmc, Storm, PRISM, Ace, Merlin, pyAgrum, pgmpy, libDAI and TensorInference.jl ran in a later run, on other machines, on the instances the release run did not give them. 27 more instances of the ladders no system ran: each system had failed on a smaller size. # Weighted model integration on a star (Zeng, Morettin, Yan, Passerini and
# Van den Broeck, ICML 2020, Section 6; the star-shaped primal graphs of
# Zeng and Van den Broeck, UAI 2019): a centre x_0 and n leaves, real
# variables uniform on [0, 1], each leaf constrained by x_0 + x_i <= 1,
# and the query x_1 <= 1/2. The constraints have volume 1/(n+1), and the
# continuous answer is (n+1)/(2n) (1 - 2^-n) + 2^-(n+1); the answer of the
# discretized program converges to it as the bits after the binary point
# grow. Each variable is a uniform fixed-point number with `bits` bits
# after the binary point; `n` is the number of leaves.
using Alea

const QUERY = :pr
const n = 16
const bits = 8
const DFiP = DistFix{2 + bits, bits}

model() = @alea begin
    x0 = uniform(DFiP, 0.0, 1.0)
    x = [uniform(DFiP, 0.0, 1.0) for i in 1:n]
    for i in 1:n
        observe(!(DFiP(1.0) < x0 + x[i]))
    end
    !(DFiP(0.5) < x[1])
end

Psi
Psi answers the Dice programs exactly, one run per component of the program's value, the times added. On its own linear regression it answers the posterior means of the continuous model, E(a) and E(b), which the circuit's bit queries do not have, so there is nothing to compare them with.

The programs of the bit-blasting paper (Garg, Holtzen, Van den Broeck and Millstein, PLDI 2024) on ladders of precision. Alea.jl runs each program itself; tddlog runs the circuit Alea.jl builds for it, and Roulette the circuit's Dice program translated to Racket. Dice's times on these circuits come from an earlier run, so they are in docs/benchmarks.md and not here. 600 s a run. Psi, Genfer, SPPL, Storm and PRISM ran too, each on the programs it takes (its own paper's, the Dice programs, the ProbLog programs or the networks); a system's time is its process's, start-up included. Roulette, Roulette's process, Storm and PRISM ran in a later run, on other machines, on the instances the release run did not give them, each beside tddlog: their times compare with that run's tddlog, not with the other columns, and the comparisons below use it. 29 more instances of the ladders no system ran: each system had failed on a smaller size. # clinicaltrial2 (Gehr et al. 2016): the success probability of the
# control group in a trial of five patients a group, given that the
# treatment is effective. Bit-blasting paper (Garg, Holtzen, Van den
# Broeck, Millstein, PLDI 2024), Table 2: 12 bits. From Tractables/Alea.jl
# hybrid/benchmarks/clinicalTrial2/clinicalTrial2.jl at cf5e5b8 (Apache
# License 2.0), its body unchanged.
using Alea, Distributions

const QUERY = :expectation
const bits = 10
const DFiP = DistFix{2+bits, bits}
const controlGroup = [false, false, true, false, false]
const treatedGroup = [true, false, true, true, true]

model() = @alea begin
    isEffective = flip(0.5)
    probIfTreated = uniform(DFiP, 0.0, 1.0)
    probIfControl = if isEffective uniform(DFiP, 0.0, 1.0) else probIfTreated end
    for i=1:5
        controlFlip = parametrised_flip(probIfControl)
        observe(controlFlip == controlGroup[i])
        treatedFlip = parametrised_flip(probIfTreated)
        observe(treatedFlip == treatedGroup[i])
    end
    observe(isEffective)
    probIfControl
end

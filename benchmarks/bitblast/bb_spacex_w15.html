bb_spacex_w15

The programs of the bit-blasting paper (Garg, Holtzen, Van den Broeck and Millstein, PLDI 2024) on ladders of precision. Alea.jl runs each program itself; tddlog runs the circuit Alea.jl builds for it, and Roulette the circuit's Dice program translated to Racket. Dice's times on these circuits come from an earlier run, so they are in docs/benchmarks.md and not here. 600 s a run. Psi, Genfer, SPPL, Storm and PRISM ran too, each on the programs it takes (its own paper's, the Dice programs, the ProbLog programs or the networks); a system's time is its process's, start-up included. Roulette, Roulette's process, Storm and PRISM ran in a later run, on other machines, on the instances the release run did not give them, each beside tddlog: their times compare with that run's tddlog, not with the other columns, and the comparisons below use it. 29 more instances of the ladders no system ran: each system had failed on a smaller size. The circuit of the Alea.jl program data/alea/hybit/spacex.jl with bits=7.

In the repository (the baselines branch): data/alea/hybit/spacex.jl.

# spacex (canyon289 2022): the expected completion time of a rocket, a sum
# of three normal durations. Bit-blasting paper (Garg, Holtzen, Van den
# Broeck, Millstein, PLDI 2024), Table 2: 19 bits, 32 pieces. From
# Tractables/Alea.jl hybrid/benchmarks/spacex/spacex.jl at cf5e5b8 (Apache
# License 2.0), its body unchanged.
using Alea, Distributions

const QUERY = :expectation
const bits = 11
const pieces = 32
const DFiP = DistFix{8+bits, bits}

model() = @alea begin
    engines = bitblast(DFiP, Normal(5, 1), pieces, 0.0, 64.0)
    first_stage = bitblast_exponential(DFiP, Normal(10, 3), pieces, 0.0, 64.0)
    completed_first_stage = engines + first_stage
    second_stage = bitblast_exponential(DFiP, Normal(15, 3), pieces, 0.0, 64.0)
    completed_rocket = completed_first_stage + second_stage
    completed_rocket
end

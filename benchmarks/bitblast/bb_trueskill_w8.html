bb_trueskill_w8

The programs of the bit-blasting paper (Garg, Holtzen, Van den Broeck and Millstein, PLDI 2024) on ladders of precision. Alea.jl runs each program itself; tddlog runs the circuit Alea.jl builds for it, and Roulette the circuit's Dice program translated to Racket. 600 s a run. Geni, noDice, Psi, Genfer, SPPL, PITA, aspmc, Storm, PRISM, Ace, Merlin, pyAgrum, pgmpy, libDAI and TensorInference.jl ran too, each on the programs it takes (its own paper's, the Dice programs, the ProbLog programs or the networks); a system's time is its process's, start-up included. Dice, Roulette, Roulette's process, ProbLog, Geni, noDice, Psi, Genfer, SPPL, PITA, aspmc, Storm, PRISM, Ace, Merlin, pyAgrum, pgmpy, libDAI and TensorInference.jl ran in a later run, on other machines, on the instances the release run did not give them, each beside tddlog: their times compare with that run's tddlog, not with the other columns, and the comparisons below use it. 27 more instances of the ladders no system ran: each system had failed on a smaller size. The circuit of the Alea.jl program data/alea/hybit/trueskill.jl with bits=2.

# trueskill (Gehr et al. 2016): two players' skills, standard normal, two
# observed matches with normal performance noise, and the probability
# that the first wins a third. Bit-blasting paper (Garg, Holtzen, Van den
# Broeck, Millstein, PLDI 2024), Table 2: 10 bits, 16 pieces. From
# Tractables/Alea.jl hybrid/benchmarks/trueskill/trueskill.jl at cf5e5b8
# (Apache License 2.0); DFiP moved out of the block, the body otherwise
# unchanged.
using Alea, Distributions

const QUERY = :pr
const bits = 4
const pieces = 16
const DFiP = DistFix{bits + 6, bits}

model() = @alea begin
    alice_skill = bitblast(DFiP, Normal(0, 1), pieces, -8.0, 8.0)
    bob_skill = bitblast(DFiP, Normal(0, 1), pieces, -8.0, 8.0)
    match = Vector(undef, 3)
    for i = 1:3
        match[i] = (bitblast(DFiP, Normal(0, 2), pieces, -16.0, 16.0) + alice_skill) < (bitblast(DFiP, Normal(0, 2), pieces, -16.0, 16.0) + bob_skill)
    end
    observe(match[1])
    observe(!match[2])
    match[3]
end

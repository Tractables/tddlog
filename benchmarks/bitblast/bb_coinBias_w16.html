bb_coinBias_w16

The programs of the bit-blasting paper (Garg, Holtzen, Van den Broeck and Millstein, PLDI 2024) on ladders of precision. Alea.jl runs each program itself; tddlog runs the circuit Alea.jl builds for it, and Roulette the circuit's Dice program translated to Racket. 600 s a run. Geni, noDice, Psi, Genfer, SPPL, aspmc, Storm, PRISM, Ace, Merlin, pyAgrum, pgmpy, libDAI and TensorInference.jl ran too, each on the programs it takes (its own paper's, the Dice programs, the ProbLog programs or the networks); a system's time is its process's, start-up included. Dice, Roulette, Roulette's process, ProbLog, Geni, noDice, Psi, Genfer, SPPL, aspmc, Storm, PRISM, Ace, Merlin, pyAgrum, pgmpy, libDAI and TensorInference.jl ran in a later run, on other machines, on the instances the release run did not give them, each beside tddlog: their times compare with that run's tddlog, not with the other columns, and the comparisons below use it. 29 more instances of the ladders no system ran: each system had failed on a smaller size. The circuit of the Alea.jl program data/alea/hybit/coinBias.jl with bits=14.

# coinBias (Gehr et al. 2016): a coin's bias, Beta(2, 5), given five
# observed tosses. Bit-blasting paper (Garg, Holtzen, Van den Broeck,
# Millstein, PLDI 2024), Table 2: 22 bits, 4096 pieces. From
# Tractables/Alea.jl hybrid/benchmarks/coinBias/coinBias.jl at cf5e5b8
# (Apache License 2.0), its body unchanged.
using Alea, Distributions

const QUERY = :expectation
const bits = 20
const pieces = 4096
const DFiP = DistFix{bits+2, bits}
const y = [1, 1, 0, 1, 0]

model() = @alea begin
    a = bitblast_exponential(DFiP, Beta(2, 5), pieces, 0.0, 1.0)
    for i = 1:5
        b = parametrised_flip(a)
        observe((y[i]!=1) | b)
        observe((y[i]==1) | !b)
    end
    return a
end

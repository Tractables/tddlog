bb_addFun_max_w17

The programs of the bit-blasting paper (Garg, Holtzen, Van den Broeck and Millstein, PLDI 2024) on ladders of precision. Alea.jl runs each program itself; tddlog runs the circuit Alea.jl builds for it, and Roulette the circuit's Dice program translated to Racket. 600 s a run. Geni, noDice, Psi, Genfer, SPPL, Pluck, PITA, aspmc, Storm, PRISM, Ace, Merlin, pyAgrum, pgmpy, libDAI and TensorInference.jl ran too, each on the programs it takes (its own paper's, the Dice programs, the ProbLog programs or the networks); a system's time is its process's, start-up included. # addfun/max (Gehr et al. 2016): the maximum of two standard normal
# numbers. Bit-blasting paper (Garg, Holtzen, Van den Broeck, Millstein,
# PLDI 2024), Table 2: 23 bits, 128 pieces. From Tractables/Alea.jl
# hybrid/benchmarks/addFun_max/addFun_max.jl at cf5e5b8 (Apache License
# 2.0), its body unchanged.
using Alea, Distributions

const QUERY = :expectation
const bits = 18
const pieces = 128
const DFiP = DistFix{5+bits, bits}

model() = @alea begin
    x = bitblast(DFiP, Normal(0, 1), pieces, -8.0, 8.0)
    y = bitblast(DFiP, Normal(0, 1), pieces, -8.0, 8.0)
    m = if (x < y) y else x end
    m
end

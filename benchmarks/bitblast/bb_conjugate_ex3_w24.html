bb_conjugate_ex3_w24

The programs of the bit-blasting paper (Garg, Holtzen, Van den Broeck and Millstein, PLDI 2024) on ladders of precision. Alea.jl runs each program itself; tddlog runs the circuit Alea.jl builds for it, and Roulette the circuit's Dice program translated to Racket. Dice's times on these circuits come from an earlier run, so they are in docs/benchmarks.md and not here. 600 s a run. Psi, Genfer, SPPL, Storm and PRISM ran too, each on the programs it takes (its own paper's, the Dice programs or the ProbLog programs); a system's time is its process's, start-up included. Roulette, Roulette's process, Storm and PRISM ran in a later run, on other machines, on the instances the release run did not give them, each beside tddlog: their times compare with that run's tddlog, not with the other columns, and the comparisons below use it. 29 more instances of the ladders no system ran: each system had failed on a smaller size. # Conjugate Gaussians with low-probability observations (bit-blasting
# paper, Garg, Holtzen, Van den Broeck, Millstein, PLDI 2024, Section 2.3,
# Figures 5 and 6): a standard normal mean and two observations, 8 and 9,
# each normal around it with variance 1; the posterior is normal with mean
# 17/3 and variance 1/3. The paper plots it at 16 bits after the binary
# point and 2048 pieces; here the program is queried for its expectation.
# From Tractables/Alea.jl hybrid/benchmarks/conjugate_gaussians/
# conjugate_gaussians.jl at cf5e5b8 (Apache License 2.0): the bits and
# pieces, read from the command line there, are constants, and the
# plotting and results file are dropped; the body is otherwise unchanged.
using Alea, Distributions

const QUERY = :expectation
const bits = 16
const pieces = 2048
const DFiP = DistFix{8 + bits, bits}
const data = DFiP.([8.0, 9.0])
const add_arg = true

model() = @alea begin
    a = bitblast(DFiP, Normal(0, 1), pieces, -16.0, 16.0)
    for datapt in data
        gaussian_observe(DFiP, pieces, -16.0, 16.0, a, 1.0, datapt, add=add_arg, exp=false)
    end
    a
end

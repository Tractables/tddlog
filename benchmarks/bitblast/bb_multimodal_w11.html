bb_multimodal_w11

The programs of the bit-blasting paper (Garg, Holtzen, Van den Broeck and Millstein, PLDI 2024) on ladders of precision. Alea.jl runs each program itself; tddlog runs the circuit Alea.jl builds for it, and Roulette the circuit's Dice program translated to Racket. 600 s a run. Geni, noDice, Psi, Genfer, SPPL, Pluck, PITA, aspmc, Storm, PRISM, Ace, Merlin, pyAgrum, pgmpy, libDAI and TensorInference.jl ran too, each on the programs it takes (its own paper's, the Dice programs, the ProbLog programs or the networks); a system's time is its process's, start-up included. Dice, Roulette, Roulette's process, ProbLog, Geni, noDice, Pluck, PITA, aspmc, Storm, PRISM, Ace, Merlin, pyAgrum, pgmpy, libDAI and TensorInference.jl ran in a later run, on other machines, on the instances the release run did not give them. 27 more instances of the ladders no system ran: each system had failed on a smaller size. The circuit of the Alea.jl program data/alea/bitblast/multimodal.jl with bits=4.

# The Yao-Vehtari-Gelman model (bit-blasting paper, Garg, Holtzen, Van den
# Broeck, Millstein, PLDI 2024, Section 2.2, Figures 3 and 4): two means
# uniform on [-16, 16], nine observations, each normal around the first
# mean with probability 2/3 and around the second otherwise; the posterior
# of the first mean is bimodal. The paper plots that posterior at 6 bits
# after the binary point and 256 pieces; here the program is queried for
# its expectation. From Tractables/Alea.jl
# hybrid/benchmarks/multimodal/multimodal.jl at cf5e5b8 (Apache License
# 2.0): the distributions are built inside the block, the plotting and
# results file are dropped, and the program is run with `ignore_errors`,
# as the source's `pr` is; the body is otherwise unchanged.
using Alea, Distributions

const QUERY = :expectation
const IGNORE_ERRORS = true
const bits = 6
const pieces = 256
const DFiP = DistFix{7 + bits, bits}
const datapt = [5.0, 5.0, 5.0, 5.0, 5.0, 5.0, -5.0, -5.0, -5.0]

model() = @alea begin
    mu1 = uniform(DFiP, -16.0, 16.0)
    mu2 = uniform(DFiP, -16.0, 16.0)
    for data in datapt
        y = ifelse(flip(2/3),
                   bitblast_exponential(DFiP, Normal(0, 1), pieces, -8.0, 8.0) + mu1,
                   bitblast_exponential(DFiP, Normal(0, 1), pieces, -8.0, 8.0) + mu2)
        observe(prob_equals(y, DFiP(data)))
    end
    (mu1)
end

bb_spacex_w13

The programs of the bit-blasting paper (Garg, Holtzen, Van den Broeck and Millstein, PLDI 2024) on ladders of precision. Alea.jl runs each program itself; tddlog runs the circuit Alea.jl builds for it, and Roulette the circuit's Dice program translated to Racket. 600 s a run. Geni, noDice, Psi, Genfer, SPPL, Pluck, PITA, aspmc, Storm, PRISM, Ace, Merlin, pyAgrum, pgmpy, libDAI and TensorInference.jl ran too, each on the programs it takes (its own paper's, the Dice programs, the ProbLog programs or the networks); a system's time is its process's, start-up included. Dice, Roulette, Roulette's process, ProbLog, Geni, noDice, Pluck, PITA, aspmc, Storm, PRISM, Ace, Merlin, pyAgrum, pgmpy, libDAI and TensorInference.jl ran in a later run, on other machines, on the instances the release run did not give them. 27 more instances of the ladders no system ran: each system had failed on a smaller size. The circuit of the Alea.jl program data/alea/hybit/spacex.jl with bits=5.

# spacex (canyon289 2022): the expected completion time of a rocket, a sum
# of three normal durations. Bit-blasting paper (Garg, Holtzen, Van den
# Broeck, Millstein, PLDI 2024), Table 2: 19 bits, 32 pieces. From
# Tractables/Alea.jl hybrid/benchmarks/spacex/spacex.jl at cf5e5b8 (Apache
# License 2.0), its body unchanged.
using Alea, Distributions

const QUERY = :expectation
const bits = 11
const pieces = 32
const DFiP = DistFix{8+bits, bits}

model() = @alea begin
    engines = bitblast(DFiP, Normal(5, 1), pieces, 0.0, 64.0)
    first_stage = bitblast_exponential(DFiP, Normal(10, 3), pieces, 0.0, 64.0)
    completed_first_stage = engines + first_stage
    second_stage = bitblast_exponential(DFiP, Normal(15, 3), pieces, 0.0, 64.0)
    completed_rocket = completed_first_stage + second_stage
    completed_rocket
end

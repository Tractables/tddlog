bb_wmi_path_n64

The programs of the bit-blasting paper (Garg, Holtzen, Van den Broeck and Millstein, PLDI 2024) on ladders of precision. Alea.jl runs each program itself; tddlog runs the circuit Alea.jl builds for it. Dice's times on these circuits come from an earlier run, so they are in docs/benchmarks.md and not here. 600 s a run. Psi, Genfer, SPPL, Storm and PRISM ran too, each on the programs it takes (its own paper's, the Dice programs or the ProbLog programs); a system's time is its process's, start-up included. Storm and PRISM ran in a later run, on other machines, on the instances the release run did not give them, each beside tddlog: their times compare with that run's tddlog, not with the other columns, and the comparisons below use it. 29 more instances of the ladders no system ran: each system had failed on a smaller size. The circuit of the Alea.jl program data/alea/wmi/path.jl with n=64.

# Weighted model integration on a path (Zeng, Morettin, Yan, Passerini and
# Van den Broeck, "Scaling up Hybrid Probabilistic Inference with Logical
# and Arithmetic Constraints via Message Passing", ICML 2020, Section 6;
# the path-shaped primal graphs of Zeng and Van den Broeck, "Efficient
# Search-Based Weighted Model Integration", UAI 2019): n real variables
# uniform on [0, 1], each pair of neighbours constrained by
# x_i + x_{i+1} <= 1, and the query x_1 <= 1/2. The continuous volume of
# the constraints is E_n / n!, E_n the n-th Euler zigzag number; the
# answer of the discretized program converges to that of the continuous
# one as the bits after the binary point grow. Each x_i is a uniform
# fixed-point number with `bits` bits after the binary point, so that a
# constraint compares a sum of two numbers with a constant; `n` is the
# length of the path.
using Alea

const QUERY = :pr
const n = 16
const bits = 8
const DFiP = DistFix{2 + bits, bits}

model() = @alea begin
    x = [uniform(DFiP, 0.0, 1.0) for i in 1:n]
    for i in 1:n-1
        observe(!(DFiP(1.0) < x[i] + x[i+1]))
    end
    !(DFiP(0.5) < x[1])
end

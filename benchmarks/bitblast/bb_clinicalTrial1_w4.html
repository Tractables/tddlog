bb_clinicalTrial1_w4

The programs of the bit-blasting paper (Garg, Holtzen, Van den Broeck and Millstein, PLDI 2024) on ladders of precision. Alea.jl runs each program itself; tddlog runs the circuit Alea.jl builds for it, and Roulette the circuit's Dice program translated to Racket. 600 s a run. Geni, noDice, Psi, Genfer, SPPL, Pluck, PITA, aspmc, Storm, PRISM, Ace, Merlin, pyAgrum, pgmpy, libDAI and TensorInference.jl ran too, each on the programs it takes (its own paper's, the Dice programs, the ProbLog programs or the networks); a system's time is its process's, start-up included. Dice, Roulette, Roulette's process, ProbLog, Geni, noDice, Psi, Genfer, SPPL, Pluck, PITA, aspmc, Storm, PRISM, Ace, Merlin, pyAgrum, pgmpy, libDAI and TensorInference.jl ran in a later run, on other machines, on the instances the release run did not give them. 27 more instances of the ladders no system ran: each system had failed on a smaller size. A process time is the whole process's, with the language's start and compilation; the other time of the same system leaves them out, as its paper times it. model() = @alea begin
    isEffective = flip(0.5)
    probControl = uniform(DFiP, 0.0, 1.0)
    probTreated = uniform(DFiP, 0.0, 1.0)
    probAll = uniform(DFiP, 0.0, 1.0)
    if isEffective
        for i in 1:100
            controlGroupFlip = parametrised_flip(probControl)
            observe(controlGroupFlip == controlData[i])
            treatedGroupFlip = parametrised_flip(probTreated)
            observe(treatedGroupFlip == treatedData[i])
        end
    else
        for i in 1:100
            controlGroupFlip = parametrised_flip(probAll)
            observe(controlGroupFlip == controlData[i])
            treatedGroupFlip = parametrised_flip(probAll)
            observe(treatedGroupFlip == treatedData[i])
        end
    end
    isEffective
end

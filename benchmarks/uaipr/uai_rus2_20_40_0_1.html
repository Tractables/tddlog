Results › Bayesian and Markov networks › UAI 2022: partition function, final set

uai_rus2_20_40_0_1

The 197 networks of the UAI 2022 competition's final PR set: tddlog prints the probability of the evidence alone (--evidence-probability --no-queries) and Merlin and the other network tools run their partition function tasks; 300 s a run. ProbLog, PITA, aspmc, Ace, Merlin, pyAgrum, pgmpy, libDAI, TensorInference.jl and the Dice family ran in a later run. Made by gen_bn.py PR_final/rus2_20_40_0_1.uai --evid PR_final/rus2_20_40_0_1.uai.evid.

Seconds, a time limit of 300 s; memory: out of memory. >300: the time limit ran out. error: the system stopped with an error. A process time is the whole process's, with the language's start and compilation; the other time of the same system leaves them out, as its paper times it. A system run in several forms (ProbLog's knowledge compilers, Ace's routes) has the time of its fastest form.

The programs

The files each system was handed, byte for byte: written by the release's scripts at the run's commit and captured by running the benchmark driver's own code with no system started. The first tab is the original program as its authors wrote it; each other tab is a translation of it into the language of the systems that read it, and says which script wrote it.

Psi (later run)

Psi answers the Dice programs exactly, one run per component of the program's value, the times added. On its own linear regression it answers the posterior means of the continuous model, E(a) and E(b), which the circuit's bit queries do not have, so there is nothing to compare them with.

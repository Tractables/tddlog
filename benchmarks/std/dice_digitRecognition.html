Seconds, a time limit of 300 s; >300: the time limit ran out. wrong: an answer off the reference by more than 1e-6. error: the system stopped with an error. memory: out of memory. A process time is the whole process's, with the language's start and compilation; the other time of the same system leaves them out, as its paper times it. A system run in several forms (ProbLog's knowledge compilers, Ace's routes) has the time of its fastest form.

The programs

The files each system was handed, byte for byte: written by the release's scripts at the run's commit and captured by running the benchmark driver's own code with no system started. The first tab is the original program as its authors wrote it; each other tab is a translation of it into the language of the systems that read it, and says which script wrote it.

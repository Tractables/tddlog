dice_twocoins

50 programs: random graphs, grids, smokers, UW-CSE, Cora citation matching, blood types and the Dice paper's programs translated to ProbLog; 300 s a run. aspmc, Ace, Merlin, pyAgrum, pgmpy, libDAI, TensorInference.jl, Storm, PRISM and the Dice family ran in a later run, each instance beside that run's tddlog, which their comparisons use. Made by dice2problog.py data/dice/twocoins.dice.

// twocoins.dice, translated by tddlog's scripts/dice2psi.py, component 0.
def main() {
  v1_firstcoin := flip(0.5);
  v2_secondcoin := flip(0.5);
  v3_bothheads := (v1_firstcoin && v2_secondcoin);
  v4_tmp := !v3_bothheads;
  observe(v4_tmp);
  return v1_firstcoin;
}

grid6

50 programs: random graphs, grids, smokers, UW-CSE, Cora citation matching, blood types and the Dice paper's programs translated to ProbLog; 300 s a run. Made by gen_grid.py 6 --seed 1.

The programs

The files each system was handed, byte for byte: written by the release's scripts at the run's commit and captured by running the benchmark driver's own code with no system started. The first tab is the original program as its authors wrote it; each other tab is a translation of it into the language of the systems that read it, and says which script wrote it.

The original: the program as its generator wrote it, handed to tddlog, ProbLog -k ddnnf, ProbLog -k sdd, ProbLog -k fsdd, aspmc as it is.

Read by tddlog, ProbLog -k ddnnf, ProbLog -k sdd, ProbLog -k fsdd, aspmc.

aspmc reads this ProbLog program as it stands, through its ProbLog front end; it has no translation of its own.

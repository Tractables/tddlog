rl_hardware_10000

The scaling programs of the Roulette paper (Moy et al., PLDI 2025) on ladders of size, and its nine Bayesian networks. Roulette runs the artifact's programs; tddlog, Dice and Alea.jl run programs of the same models. On caesar Roulette's time is that of its query with #f, which keeps the answer. 600 s a run. Geni, noDice, Psi, Genfer, SPPL, Pluck, PITA, aspmc, Storm, PRISM, Ace, Merlin, pyAgrum, pgmpy, libDAI and TensorInference.jl ran too, each on the programs it takes (its own paper's, the Dice programs, the ProbLog programs or the networks); a system's time is its process's, start-up included. ProbLog, Geni, noDice, Psi, Genfer, SPPL, Pluck, PITA, aspmc, Storm, PRISM, Ace, Merlin, pyAgrum, pgmpy, libDAI and TensorInference.jl ran in a later run, on other machines, on the instances the release run did not give them, each beside tddlog: their times compare with that run's tddlog, not with the other columns, and the comparisons below use it. Made by gen_roulette.py hardware 10000.

Seconds, a time limit of 600 s; skipped: not run: the system had failed on a smaller size of the same program. memory: out of memory. error: the system stopped with an error. >600: the time limit ran out. A process time is the whole process's, with the language's start and compilation; the other time of the same system leaves them out, as its paper times it. A time is the median of the repetitions below, a failed one counted as infinite. A system run in several forms (ProbLog's knowledge compilers, Ace's routes) has the time of its fastest form.

The files each system was handed, byte for byte: written by the release's scripts at the run's commit and captured by running the benchmark driver's own code with no system started. Roulette's own program of this benchmark, from its artifact (data/roulette/README.md): not a translation, the system's own program.

#lang racket/base
;; racket hardware.rkt FUEL: benchmark/scaling/hardware.rkt of the
;; Roulette artifact under rsdd with bit width 2 and n = FUEL - 2 (`-m rsdd
;; -p (2 n FUEL)`, the artifact's fuel ladder), its distribution printed
;; in full (print.rkt): res(T) for a total T, res(4) for #f (out of fuel).
(require (submod roulette/benchmark/scaling/hardware rsdd)
         roulette/example/private/pmf
         "print.rkt")
(define fuel (string->number (vector-ref (current-command-line-arguments) 0)))
(define result (main 2 (max 0 (- fuel 2)) fuel))
(for ([(v p) (in-pmf result)])
  (emit (format "res(~a)" (or v 4)) p))

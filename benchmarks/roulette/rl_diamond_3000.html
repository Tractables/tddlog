rl_diamond_3000

The scaling programs of the Roulette paper (Moy et al., PLDI 2025) on ladders of size, and its nine Bayesian networks. Roulette runs the artifact's programs; tddlog, Dice and Alea.jl run programs of the same models. On caesar Roulette's time is that of its query with #f, which keeps the answer. 600 s a run. Geni, noDice, Psi, Genfer, SPPL, Pluck, PITA, aspmc, Storm, PRISM, Ace, Merlin, pyAgrum, pgmpy, libDAI and TensorInference.jl ran too, each on the programs it takes (its own paper's, the Dice programs, the ProbLog programs or the networks); a system's time is its process's, start-up included. ProbLog, Geni, noDice, Psi, Genfer, SPPL, Pluck, PITA, aspmc, Storm, PRISM, Ace, Merlin, pyAgrum, pgmpy, libDAI and TensorInference.jl ran in a later run, on other machines, on the instances the release run did not give them, each beside tddlog: their times compare with that run's tddlog, not with the other columns, and the comparisons below use it. Made by gen_roulette.py diamond 3000.

A process time is the whole process's, with the language's start and compilation; the other time of the same system leaves them out, as its paper times it. A time is the median of the repetitions below, a failed one counted as infinite. A system run in several forms (ProbLog's knowledge compilers, Ace's routes) has the time of its fastest form.

Roulette's own program of this benchmark, from its artifact (data/roulette/README.md): not a translation, the system's own program.

#lang roulette/example/disrupt
;; benchmark/modular/diamond.rkt of the Roulette artifact (Zenodo
;; 10.5281/zenodo.15253254), its last line changed to print P(s(N)) in
;; full (print.rkt).
(require "print.rkt")

(define (main n)
  (let go ([n n])
    (cond
      [(zero? n) #t]
      [else
       (define drop (flip 0.0001))
       (define route (flip 0.5))
       (define s1 (go (sub1 n)))
       (define s2 (if route s1 #f))
       (define s3 (if route #f s1))
       (or s2 (and s3 (not drop)))])))

(define SIZE (string->number (vector-ref (current-command-line-arguments) 0)))
(define result (time (query (main SIZE))))
(emit (format "s(~a)" SIZE) (result #t))

Geni (later run)
Geni computes in single precision and prints seven decimals, so differences of up to 5e-8 from the reference are its print precision.
Not run in any repetition: not run: the system had failed on a smaller size of the same program.


noDice (later run)
Not run in any repetition: not run: the system had failed on a smaller size of the same program.


Psi (later run)
Psi answers the Dice programs exactly, one run per component of the program's value, the times added. On its own linear regression it answers the posterior means of the continuous model, E(a) and E(b), which the circuit's bit queries do not have, so there is nothing to compare them with.
Not run in any repetition: not run: the system had failed on a smaller size of the same program.


Genfer (later run)
Genfer answers its own program: the Dice programs of its comparison in exact rationals, the population model in floating point (its masses summed over the bits of the circuit).
Not run in any repetition: not run: the system had failed on a smaller size of the same program.


SPPL (later run)
SPPL answers the continuous model, with normal emissions as densities; the circuit rounds them to a grid, so the differences from the reference are that discretization.
Not run in any repetition: not run: the system had failed on a smaller size of the same program.

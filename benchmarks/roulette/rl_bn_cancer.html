rl_bn_cancer

The scaling programs of the Roulette paper (Moy et al., PLDI 2025) on ladders of size, and its nine Bayesian networks. Roulette runs the artifact's programs; tddlog, Dice and Alea.jl run programs of the same models. On caesar Roulette's time is that of its query with #f, which keeps the answer. 600 s a run. Geni, noDice, Psi, Genfer, SPPL, Pluck, PITA, aspmc, Storm, PRISM, Ace, Merlin, pyAgrum, pgmpy, libDAI and TensorInference.jl ran too, each on the programs it takes (its own paper's, the Dice programs, the ProbLog programs or the networks); a system's time is its process's, start-up included. ProbLog, Geni, noDice, Psi, Genfer, SPPL, Pluck, PITA, aspmc, Storm, PRISM, Ace, Merlin, pyAgrum, pgmpy, libDAI and TensorInference.jl ran in a later run, on other machines, on the instances the release run did not give them. Made by gen_bn.py roulette-artifact/bayesian-networks/cancer.bif --query Xray.

Roulette's own program of this benchmark, from its artifact (data/roulette/README.md): not a translation, the system's own program.

#lang racket/base
;; racket bayes.rkt NAME: the Bayesian network NAME of the Roulette
;; artifact's benchmark/main.rkt (its .bif, queried variable and variable
;; order, read from main.rkt as the artifact's driver builds them) under
;; benchmark/bayes.rkt with rsdd, its distribution printed in full:
;; `roulette_v VALUE P` for each value of the queried variable.
(require (submod roulette/benchmark/bayes rsdd)
         roulette/example/private/pmf
         racket/match
         racket/path)
(define name (vector-ref (current-command-line-arguments) 0))
(define dir (path-only (collection-file-path "main.rkt" "roulette" "benchmark")))
(define body
  (let* ([mod (parameterize ([read-accept-reader #t])
                (call-with-input-file (build-path dir "main.rkt") read))]
         [b (cadddr mod)])
    (if (eq? (car b) '#%module-begin) (cdr b) (cdddr mod))))
(define def
  (for/first ([f body] #:when (and (pair? f) (eq? (car f) 'define)
                                   (eq? (cadr f) (string->symbol (string-upcase name)))))
    (caddr f)))
(define params
  (match def
    [(list 'quasiquote (list (list 'unquote (list 'bif n)) q order))
     (list (path->string (build-path dir "bayesian-networks" (format "~a.bif" n))) q order)]
    [_ (error 'bayes.rkt "no network ~a in main.rkt" name)]))
(define result (apply main params))
(for ([(v p) (in-pmf result)])
  (printf "roulette_v ~a ~a\n" v (if (exact? p) (exact->inexact p) p)))

Psi (later run)

Psi answers the Dice programs exactly, one run per component of the program's value, the times added. On its own linear regression it answers the posterior means of the continuous model, E(a) and E(b), which the circuit's bit queries do not have, so there is nothing to compare them with.

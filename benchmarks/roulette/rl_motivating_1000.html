rl_motivating_1000

The scaling programs of the Roulette paper (Moy et al., PLDI 2025) on ladders of size, and its nine Bayesian networks. Roulette runs the artifact's programs; tddlog, Dice and Alea.jl run programs of the same models. On caesar Roulette's time is that of its query with #f, which keeps the answer. 600 s a run. Geni, noDice, Psi, Genfer, SPPL, Pluck, PITA, aspmc, Storm, PRISM, Ace, Merlin, pyAgrum, pgmpy, libDAI and TensorInference.jl ran too, each on the programs it takes (its own paper's, the Dice programs, the ProbLog programs or the networks); a system's time is its process's, start-up included. ProbLog, Geni, noDice, Psi, Genfer, SPPL, Pluck, PITA, aspmc, Storm, PRISM, Ace, Merlin, pyAgrum, pgmpy, libDAI and TensorInference.jl ran in a later run, on other machines, on the instances the release run did not give them. Made by gen_roulette.py motivating 1000.

Seconds, a time limit of 600 s; >600: the time limit ran out. memory: out of memory. A process time is the whole process's, with the language's start and compilation; the other time of the same system leaves them out, as its paper times it. A time is the median of the repetitions below, a failed one counted as infinite. A system run in several forms (ProbLog's knowledge compilers, Ace's routes) has the time of its fastest form.

The files each system was handed, byte for byte: written by the release's scripts at the run's commit and captured by running the benchmark driver's own code with no system started. Roulette's own program of this benchmark, from its artifact (data/roulette/README.md): not a translation, the system's own program.

#lang roulette/example/disrupt
;; benchmark/modular/motivating.rkt of the Roulette artifact (Zenodo
;; 10.5281/zenodo.15253254), its last line changed to print P(x(N)) in
;; full (print.rkt).
(require "print.rkt")

(define (main n)
  (let go ([n n])
    (cond
      [(zero? n) (flip 0.1)]
      [else
       (define x (flip 0.2))
       (define y (flip 0.3))
       (if (go (sub1 n)) x y)])))

(define SIZE (string->number (vector-ref (current-command-line-arguments) 0)))
(define result (time (query (main SIZE))))
(emit (format "x(~a)" SIZE) (result #t))

mnist_sum4

39 programs of six families from published evaluations (mnist_sum, pedigree, sickness, noisy-or, mastermind, pdb), each grown on a random structure from a seed; 300 s a run. ProvSQL ran on the two tuple-independent families, pdb and noisy-or (the others are recursive or have annotated disjunctions), in a later run on another machine, each instance beside tddlog: its times compare with that run's tddlog, which its comparison uses. Made by gen_mnist_sum.py 4 --seed 1.

The programs

The files each system was handed, byte for byte: written by the release's scripts at the run's commit and captured by running the benchmark driver's own code with no system started.

noisyor20_30

39 programs of six families from published evaluations (mnist_sum, pedigree, sickness, noisy-or, mastermind, pdb), each grown on a random structure from a seed; 300 s a run. ProvSQL ran on the two tuple-independent families, pdb and noisy-or (the others are recursive or have annotated disjunctions), in a later run on another machine, each instance beside tddlog: its times compare with that run's tddlog, which its comparison uses. aspmc, Ace, Merlin, pyAgrum, pgmpy, libDAI, TensorInference.jl and the Dice family ran in a later run, each instance beside that run's tddlog, which their comparisons use. Made by gen_noisyor.py 20 30 --seed 1.

Seconds, a time limit of 300 s; >300: the time limit ran out. skipped: not run: the system had failed on a smaller size of the same program. A process time is the whole process's, with the language's start and compilation; the other time of the same system leaves them out, as its paper times it. A system run in several forms (ProbLog's knowledge compilers, Ace's routes) has the time of its fastest form.

The files each system was handed, byte for byte: written by the release's scripts at the run's commit and captured by running the benchmark driver's own code with no system started.

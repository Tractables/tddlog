uai_objectdetection_68

The 120 networks of the UAI 2022 competition's MAR tuning set: tddlog prints the probability of the evidence alone (--evidence-probability --no-queries) and Merlin and the other network tools run their partition function tasks; 300 s a run. Made by gen_bn.py MAR_tune/ObjectDetection_68.uai --evid MAR_tune/ObjectDetection_68.uai.evid.

The programs

The files each system was handed, byte for byte: written by the release's scripts at the run's commit and captured by running the benchmark driver's own code with no system started. The first tab is the original program as its authors wrote it; each other tab is a translation of it into the language of the systems that read it, and says which script wrote it.

The original: the program as its authors wrote it, handed to Merlin, Merlin (PR), pyAgrum, pyAgrum (PR), pgmpy, pgmpy (PR), libDAI, libDAI (PR), TensorInference.jl treesa, TensorInference.jl treesa (PR), TensorInference.jl greedy, TensorInference.jl greedy (PR) as it is.

uai_objectdetection_57

The 120 networks of the UAI 2022 competition's MAR tuning set: tddlog prints the probability of the evidence alone (--evidence-probability --no-queries) and Merlin and the other network tools run their partition function tasks; 300 s a run. Made by gen_bn.py MAR_tune/ObjectDetection_57.uai --evid MAR_tune/ObjectDetection_57.uai.evid.

The programs

The files each system was handed, byte for byte: written by the release's scripts at the run's commit and captured by running the benchmark driver's own code with no system started.

uai_objectdetection_36

The 120 Markov and Bayesian networks of the UAI 2022 competition's MAR tuning set, each with its evidence; every marginal given the evidence; 300 s a run. aspmc, Ace, Storm, PRISM and the Dice family ran in a later run, each instance beside that run's tddlog, which their comparisons use. Made by gen_bn.py MAR_tune/ObjectDetection_36.uai --evid MAR_tune/ObjectDetection_36.uai.evid.

Seconds, a time limit of 300 s; >300: the time limit ran out. memory: out of memory. error: the system stopped with an error. A process time is the whole process's, with the language's start and compilation; the other time of the same system leaves them out, as its paper times it. A system run in several forms (ProbLog's knowledge compilers, Ace's routes) has the time of its fastest form.

The programs

The files each system was handed, byte for byte: written by the release's scripts at the run's commit and captured by running the benchmark driver's own code with no system started. The first tab is the original program as its authors wrote it; each other tab is a translation of it into the language of the systems that read it, and says which script wrote it.

Psi (later run)

Psi answers the Dice programs exactly, one run per component of the program's value, the times added. On its own linear regression it answers the posterior means of the continuous model, E(a) and E(b), which the circuit's bit queries do not have, so there is nothing to compare them with.

Not run in any repetition: not run: the system had failed on a smaller size of the same program.

Genfer (later run)

Genfer answers its own program: the Dice programs of its comparison in exact rationals, the population model in floating point (its masses summed over the bits of the circuit).

Not run in any repetition: not run: the system had failed on a smaller size of the same program.

SPPL (later run)

SPPL answers the continuous model, with normal emissions as densities; the circuit rounds them to a grid, so the differences from the reference are that discretization.

Not run in any repetition: not run: the system had failed on a smaller size of the same program.

Geni (later run)

Geni computes in single precision and prints seven decimals, so differences of up to 5e-8 from the reference are its print precision.

Not run in any repetition: not run: the system had failed on a smaller size of the same program.

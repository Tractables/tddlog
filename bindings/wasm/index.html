tddlog: exact probabilistic inference

Pick an example or write a ProbLog program, and press Run: tddlog gives each query's exact probability, here in this tab. It grounds the program and compiles it bottom-up into tree decision diagrams with the tididi library; nothing is uploaded. The same solver runs from the command line, Rust, Python and C, as the guide shows.

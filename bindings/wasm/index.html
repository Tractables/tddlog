tddlog: exact probabilistic inference

Pick an example or write a program in the Datalog fragment of ProbLog, and press Run: tddlog grounds it, compiles it bottom-up into tree decision diagrams with the tididi library, and gives each query's exact probability. It runs in this tab and nothing is uploaded. The same solver runs from the command line, Rust, Python and C, as the guide shows.

From the release run against the exact systems people use for each kind of problem (ProbLog, Ace, Merlin, Dice, Alea.jl and more), every answer of tddlog's checked against a reference: the plots, the tables and the findings.
